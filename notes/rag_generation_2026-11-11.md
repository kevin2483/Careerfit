# RAG 생성 단계 사전 등록 (2026-11-11, 생성 실행 전)

검색 비교(`notes/rag_experiment_2026-11-05.md`, 결과 `data/processed/rag_comparison.csv`)가 끝난 뒤의 별도 실험이다.
이 문서를 커밋한 뒤에 코드를 쓰고, 실제 질문으로는 **한 번만** 생성한다. 결과를 보고 프롬프트·모델·검색 방식을 바꾸지 않는다.
다시 하려면 새 문서를 쓰고 "2차"로 적는다.

## 무엇을 만드나
질문 → hybrid 검색 상위 문단 → LLM 이 그 문단만 근거로 답 → 답의 각 주장에 인용 문단을 붙인다.
근거가 없으면 "해당하는 공고 없음"으로 답한다.

## 고정값

| 항목 | 값 | 근거 |
|---|---|---|
| 질문 | `data/labeled/rag_queries.jsonl` 30개 그대로 | 검색 비교와 같은 질문. 새로 쓰지 않는다 |
| 검색 방식 | hybrid | 주 비교에서 확정된 것은 hybrid − vector 뿐이고, hybrid 는 bm25 와 확정 불가이나 모든 지표의 점추정이 bm25 이상, p90 245ms. 리랭커는 주 지표 확정 불가 + p90 6.1초라 쓰지 않는다. 사용자 결정 (2026-11-11) |
| 전달 문단 | 커밋된 `data/processed/rag_runs/hybrid.jsonl` 의 상위 5 (D 유형은 상위 3) | 검색을 다시 돌리지 않는다. 전달 문단 전부에 사람의 관련성 판정이 이미 있다 (부록 A7 의 판정 깊이와 같다) |
| 생성 모델 | `claude-sonnet-5-5`, effort `medium`, `max_tokens` 8000 | 사용자 결정. 샘플링 파라미터는 이 모델이 받지 않아 지정하지 않는다 |
| 호출 | 질문당 1회, 총 30회. 비스트리밍 | |
| 출력 형식 | 구조화 출력(JSON 스키마): `answerable`(bool), `claims`(목록: `text`, `source` 번호) | 주장 분할을 사람이나 다른 모델이 사후에 하지 않도록, 생성 모델이 처음부터 주장 단위로 낸다 |
| 주장 수 | 답변당 최대 2개, 각 한 문장, 각 주장은 문단 하나만 인용 | 사람 판정 최대 60건. 사용자 결정 |
| 거절 시 대체 모델 | 쓰지 않는다 | 실험 도중 모델이 바뀌면 안 된다. 거절(`stop_reason: refusal`)은 실패 행으로 센다 |

## 프롬프트 (고정)

시스템:
```
당신은 채용공고 검색 결과를 요약해 답하는 도우미다.
사용자 질문과 번호가 붙은 채용공고 문단들이 주어진다. 문단은 검색기가 찾은 것이라 질문과 무관한 것이 섞여 있을 수 있다.

규칙:
- 주어진 문단에 적힌 내용만 쓴다. 문단에 없는 사실, 일반 상식, 추측을 더하지 않는다.
- 질문의 조건을 직접 담은 문단이 하나도 없으면 answerable 을 false 로 하고 claims 를 비운다. 억지로 답하지 않는다.
- 답할 수 있으면 answerable 을 true 로 하고 claims 에 주장을 1개 또는 2개 쓴다.
- 주장 하나는 한 문장이고, 어느 회사의 공고가 무엇을 요구·우대·제공하는지를 문단의 표현에 맞춰 쓴다. "우대"를 "필수"로 바꾸는 식으로 강도를 바꾸지 않는다.
- 주장마다 근거 문단 번호 하나를 source 에 적는다. 그 문단만 읽고도 주장이 확인되어야 한다.
- 한국어로 쓴다.
```

사용자 메시지:
```
질문: {question}

[1] {title} · {company} · {section}
{text}

[2] ...
```
문단 순서는 hybrid 순위 그대로다.

## 실패 처리
- 실패 행: JSON 파싱 실패, 주장 3개 이상, `source` 가 전달 문단 번호 밖, `answerable=true` 인데 주장 0개, `answerable=false` 인데 주장이 있음, `stop_reason` 이 `end_turn` 이 아님(잘림·거절).
- 실패 행은 고치거나 조용히 다시 부르지 않는다. 건수와 사유를 결과표에 적고, 재호출 여부는 사람이 정한다 (CLAUDE.md ⑤). 재호출하면 그 사실을 부록에 적는다.
- 네트워크 오류·429·5xx 로 응답 자체를 못 받은 경우만 SDK 기본 재시도를 쓴다 (응답 내용을 보고 고르는 것이 아니다).

## 판정 (사람)
- 대상: 생성된 주장 전부 (최대 60건). 판정자 1명(사용자). AI 가 판정을 채우지 않는다.
- 화면: 질문, 주장 한 문장, 그 주장이 인용한 문단(제목·회사·구역 포함). 한 건씩, 기본값 없음, 건마다 저장.
- 묻는 것: **"이 주장이 인용한 문단에 실제로 있는 말인가?"** y/n.
- 기준 (판정 전 고정):
  - 주장의 내용이 전부 그 문단(제목·회사·구역 표시 포함)에서 확인되면 y.
  - 일부만 확인되거나, 강도가 바뀌었거나(우대 → 필수, 일부 → 전부), 문단에 없는 내용이 섞였으면 n.
  - 표현이 달라도 뜻이 같으면 y. 애매하면 n.
  - 질문에 맞는 답인지는 여기서 따지지 않는다. 문단에 있는 말인지만 본다.
- 재판정: 10%(올림)를 seed 42 로 뽑아 1차 답을 가리고 다시 판정한다. 자기 일치율로 보고한다.
- 입력 방식은 처음부터 끝까지 한 건씩이다. 바꾸면 부록에 적는다.

## 지표

| 지표 | 정의 | 비고 |
|---|---|---|
| 충실도 (주 지표) | 사람이 y 로 판정한 주장 / 전체 주장 | 95% CI 는 질문 단위 부트스트랩(B=10,000, seed 42). 주장이 있는 질문만 리샘플 |
| 거절 2×2 | (전달 문단에 관련 문단 있음/없음) × (답함/거절) 건수 | "관련 문단"은 검색 판정(`rag_judgments.jsonl`)의 y. 사전 집계: 없음 5개(q25, q26, q27, q29, q30), 있음 25개 |
| 올바른 거절률 | 관련 문단이 없는 질문 중 거절한 비율 | 분모 5 라 비율보다 건수로 읽는다 |
| 답변율 | 관련 문단이 있는 질문 중 답한 비율 | |
| 인용 적합도 (보조, 자동) | 주장이 인용한 문단이 검색 판정에서 y 였던 비율 | 사람 추가 판정 없음 |
| 실패 행 | 사유별 건수 | 0 이어도 적는다 |
| 생성 지연·토큰 | 호출별 실측 중앙값·p90, 입력·출력 토큰 합 | 1회 실측 그대로 |
| LLM 판정 일치율 (보조) | 같은 주장을 `claude-opus-5-5` (effort `medium`) 가 같은 기준으로 y/n 판정한 것과 사람 판정의 일치율, 2×2 건수 | 사람 판정이 전부 끝난 뒤에 돌린다. 충실도 점수에는 사람 판정만 쓴다. "LLM 판정으로 사람을 대신할 수 있는가"를 보는 참고 수치 |

- 가설·합격선은 두지 않는다. 방식 비교가 없는 단일 구성의 측정이다.
- 충실도 점추정이 0.98 이상이면 성과로 쓰지 않고, 과제가 쉬운 탓(주장 최대 2개·발췌형)인지 사람에게 확인을 요청한다 (CLAUDE.md ⑤ 준용).

## 범위 밖
- 답이 질문에 얼마나 잘 맞는지(답변 적합성), 빠뜨린 공고가 있는지(완전성)는 재지 않는다.
- 프롬프트 변형 비교, 모델 비교, 검색 방식별 생성 비교는 하지 않는다.
- 점수 임계값으로 거절하는 장치는 만들지 않는다. 거절은 모델 판단에만 맡기고 그 결과를 잰다.

## 산출물
- `data/processed/rag_generation/answers.jsonl` — 질문별 답(주장, 인용 chunk_id, 전달 chunk_id, 실패 사유, 토큰, 지연)

## 코드를 쓰는 동안 지킬 것
- 프롬프트는 위 문구 그대로 코드에 넣는다. 테스트는 가짜 응답으로만 하고, 실제 질문 30개로 미리 호출해 보지 않는다.
- API 키는 사용자가 자기 터미널 환경에 둔다. 실제 호출 명령은 사용자가 실행한다.

## 부록 B1. 판정 시연 1건 (2026-11-12, 주장 판정 1건을 마친 시점)
- 판정자가 판정 방법을 이해하지 못해, 요청에 따라 AI(Claude)가 주장 1건(`q02:2`)의 판정 과정을 실제 건으로 보여 주고 답(y)을 말했다. 입력은 판정자가 했다.
- 따라서 43건 중 이 1건은 "사람만의 판정"이 아니다. 판정 파일에서 빼지는 않고, 결과 보고에 "1건은 AI 시연"으로 적는다.
- 나머지 건에 대해서는 AI 가 답을 말하지 않는다.
