# BDAI 5회차 · 에이전트 기획안 정리와 HTML

> **함께 쓰는 파일**
> `기획안_템플릿.md`  여덟 칸 뼈대. 수강생 폴더로 복사해 채운다
> `_리포트_뼈대.html`  HTML 한 장의 뼈대. **백지에서 만들지 않는다. 이것을 복사해 값만 채운다**
>
> 이 스킬은 게이트형이다. 한 번에 여러 STEP을 실행하지 않는다.
> **오늘 여기서 만드는 것은 둘이다.** `기획안.md` 와 `에이전트_소개.html`

## 진행 원칙 (Claude가 지킬 것)

1. **파일에 있는 것을 묻지 않는다.** 이 스킬의 값어치가 여기에 있다.
   여덟 칸 중 일곱 칸은 폴더를 읽어 채우고, 수강생은 확인하고 고치기만 한다.
2. **경로를 먼저 받는다.** STEP 0을 건너뛰지 않는다.
   다만 검토에서 바로 이어 온 경우에는 그 폴더를 그대로 쓴다. 다시 묻지 않는다.
3. **한 STEP씩.** 초안을 다 보여주고 한꺼번에 확인받지 않는다. 칸 묶음으로 나눠 보여준다.
4. 심사는 셋에만 건다. 나머지는 확인만 받고 넘어간다.
   - 판단 기준 세 줄에 숫자가 있는가
   - 결과에 파일 이름과 칸 구성이 있는가
   - 쓰기를 가진 담당자가 한 명인가
5. **HTML은 뼈대를 복사해 값만 채운다.** 새로 만들면 매번 다르게 나오고 규격이 깨진다.
6. HTML이 지킬 세 조건은 어길 수 없다.
   500KB 미만 · 폭을 좁혀도 가로 스크롤 없음 · **바깥에서 아무것도 불러오지 않는다.**
7. **실명 점검은 통과 필수다.** 발표 화면에 남의 이름이 뜨면 그때는 늦다.
8. 복붙 우선: 수강생이 칠 프롬프트는 코드 블록으로 준다.
9. 없어도 멈추지 않는다. `검토결과.md` 가 없으면 그 절만 비우고 진행한다.
10. 안전 먼저: 되돌리기 어려운 일은 사람 확인 없이 실행하지 않는다.

## 시작 멘트 (문장을 직접 쳐서 불렀을 때만 출력)

**검토에서 바로 이어 온 경우에는 이 멘트를 출력하지 않는다.** 방금 한 실습의 연장이다.

```
5회차 두 번째 실습, 기획안 정리와 발표 자료 만들기입니다.

── 오늘은 거의 안 여쭤봅니다 ──────────────
  만드신 폴더 안에 이미 답이 다 있습니다.
  CLAUDE.md · 담당자 파일 · 운영 스킬 · 검토결과.
  제가 읽어서 채우고, 맞는지만 확인해 주시면 됩니다.

  제가 여쭐 것은 셋뿐입니다.
    ① 혼자 하면 몇 시간 걸리던 일인가   (파일에 없습니다)
    ② 누가 쓰나
    ③ 안 됐던 것과 다음에 할 것

── 무엇이 나오나 ─────────────────────────
  기획안.md            여덟 칸 (과제 제출용)
  에이전트_소개.html    한 장 (발표에서 가장 먼저 여실 것)

  6회차에는 셋을 보여드립니다. 소개 html · 실제 결과물 파일 · 검토 html.
  발표 자료를 따로 만드실 것 없습니다.

── 얼마나 걸리나 ─────────────────────────
  30분입니다.

시작하겠습니다.
```

바로 이어서 STEP 0 갈래 B의 질문을 던진다.

# STEP 0. 경로 받고 초안 채우기 (~8분)

**시작하기 전에 어느 쪽인지 먼저 가른다.** 둘 중 하나다.

## 갈래 A · 검토에서 바로 이어 온 경우 (같은 대화에서 `bdai-5-review` 를 막 마쳤다)

- **시작 멘트를 출력하지 않는다.** 방금 한 실습의 연장이다.
- **경로를 묻지 않는다.** 아래 갈래 B의 안내 멘트도 쓰지 않는다. 방금 검토한 그 폴더를 그대로 쓴다.
- 한 줄만 말하고 바로 초안 채우기로 들어간다.
  ```
  방금 검토하신 폴더 그대로 이어가겠습니다. 이제 한 장으로 정리하겠습니다.
  ```
- 앱을 껐다 켤 일이 없다. 새로 만드는 폴더가 없기 때문이다. 그 안내를 하지 않는다.

## 갈래 B · 따로 불려 온 경우 (문장을 직접 쳐서 시작했다)

시작 멘트를 출력한 뒤 이 안내 멘트를 이어서 낸다:
```
4회차에 만드신 에이전트 폴더를 알려 주세요.

  폴더를 이 창으로 끌어다 놓으시거나, 경로를 붙여 넣으시면 됩니다.

  ★ 지금 열려 있는 폴더가 그것이면 "여기" 라고만 하셔도 됩니다.
```

Claude 실행 규칙:
- **`검토결과.md` 가 보이면** 이렇게 말하고 확인만 받는다.
  "방금 검토하신 그 폴더군요. 3축 판정을 그대로 가져다 쓰겠습니다."
- 현재 폴더에 `CLAUDE.md` 와 `.claude/agents/` 가 둘 다 있으면 묻지 않고 확인만 받는다.
- 경로에 공백이나 한글이 있으면 따옴표로 감싼다.
- 세 파일이 하나도 없으면 다시 묻는다. 최대 두 번.
  세 번째에는 상위 폴더에서 `CLAUDE.md` 를 찾아 후보를 보여주고 고르게 한다.

**여기서부터는 두 갈래가 같다.**

## 읽어오는 자리 (묻지 않는다)

| 기획안 칸 | 어디서 읽어오나 |
|---|---|
| ① 무엇을 되게 했나 | `CLAUDE.md` ① 이 폴더는 무엇을 하는 곳인가 |
| ③ 자료는 어디에 | `CLAUDE.md` ② 자주 쓰는 자료는 어디에 있나 |
| ④ 결과는 어디에 어떤 모양 | `CLAUDE.md` ③ + **실제 결과 파일의 칸과 건수** |
| ⑤ 판단 기준 세 줄 | `CLAUDE.md` ⑥ 판단 기준 |
| ⑥ 멈추는 자리 | `CLAUDE.md` ④ 절대 하지 말 것 + ⑤ 언제 멈추고 물을 것인가 |
| ⑦ 담당자와 손의 크기 | `.claude/agents/*.md` 의 `tools` 줄 |
| ⑦ 부르는 순서 | 운영 스킬(`.claude/skills/○○팀-돌리기/SKILL.md`)의 `순서` 칸 |
| ⑧ 검토 판정 | `검토결과.md` |

**④번 칸은 CLAUDE.md만 보고 채우지 않는다.** 실제 결과 파일을 열어 열 이름과 건수를 세어 적는다.
적혀 있는 것과 실제가 다르면 **실제를 적고 그 사실을 알려준다.** 대개 실제가 맞다.

## 초안을 보여주는 방법

`기획안_템플릿.md` 를 수강생 폴더에 `기획안.md` 로 복사한 뒤, 채운 칸을 **세 묶음으로 나눠** 보여준다.
한꺼번에 다 보여주면 읽지 않는다.

```
[묶음 1] 무엇을 · 어디 자료로 · 무엇이 나오나
  ① 매주 나오는 공고 20건을 역량·조건·변화 세 칸 표 한 장으로 정리한다
  ③ ./자료/공고_2026-08.csv  (20행 · 회사명·제목·본문 3열)
  ④ ./결과/역량표_260812.md  (회사·역량·조건·변화 4열 · 20행)

  맞나요? 고칠 곳 있으면 말씀해 주세요.
```

묶음 2는 담당자와 순서, 묶음 3은 판단 기준과 멈추는 자리로 나눈다.
⑧ 검토 판정은 `검토결과.md` 에서 그대로 옮기므로 묶음에 넣지 않고 옮겼다는 것만 알려준다.

## 심사는 셋에만 건다

| 확인할 것 | 반려 사유 | 되묻는 말 |
|---|---|---|
| 판단 기준 세 줄 | `이상하면` · `알아서` · `적절히` · `필요하면` 이 있다 | "그걸 무엇으로 세면 알 수 있나요?" |
| 결과 | 파일 이름이나 칸 구성이 없다 | "파일 이름과 열 이름을 적어 주세요" |
| 담당자 | 쓰기를 가진 사람이 둘 이상이다 | "쓰기는 한 명에게만 줍니다. 누가 결과 파일에 쓰나요?" |

- 세 줄 중 **최소 두 줄**에 숫자가 있으면 통과다.
- 나머지 칸은 확인만 받는다. 심사하지 않는다. **이미 4회차와 검토에서 걸렀다.**

✅ 체크포인트: "일곱 칸이 다 채워졌고, 맞는지 확인하셨나요?"

# STEP 1. 사람에게 셋만 묻기 (~6분)

**하나씩 묻는다.** 세 개를 한꺼번에 던지지 않는다.

## 질문 1. 혼자 하면 몇 시간 걸리던 일인가

```
이건 파일에 없어서 여쭙습니다. 발표에서 가장 중요한 숫자입니다.

  "이 일을 손으로 하면 얼마나 걸리셨나요?"

  대략이어도 됩니다. 반나절, 세 시간, 이틀. 이 정도면 충분합니다.
```

Claude 실행 규칙:
- "안 해봐서 모르겠다"는 답이 나오면 이렇게 묻는다.
  "한 건만 손으로 하면 몇 분 걸릴까요? 그걸 건수만큼 곱해 보세요."
- 지금 에이전트가 도는 시간과 나란히 적는다. **이 대비가 발표 첫 장이다.**
  `혼자 여섯 시간 → 지금 4분`

## 질문 2. 누가 쓰나

```
셋 중 하나를 고르시면 됩니다.

  나만 쓴다      틀려도 내가 고치면 됩니다
  팀이 쓴다      나오는 모양이 매번 같아야 합니다
  밖으로 나간다  사람이 확인하는 자리가 반드시 있어야 합니다
```

- "밖으로 나간다"를 고르면 `CLAUDE.md` ⑤에 사람 확인 자리가 있는지 그 자리에서 본다.
  없으면 한 줄 넣게 한다.

## 질문 3. 안 됐던 것과 다음에 할 것

```
두 가지만 여쭙습니다.

  ① 만들면서 막혔던 것 중, 아직 안 풀린 것이 있나요?
  ② "이것도 되면 좋겠는데" 하고 미뤄 두신 것이 있나요?
```

Claude 실행 규칙:
- `검토결과.md` 의 `아직 안 된 것` 칸이 있으면 **먼저 읽어주고** 더 있는지만 묻는다.
- "특별히 없었습니다"가 나오면 다시 묻는다. **막힌 데 없이 만든 사람은 없다.**
  "4회차에 재시작하셨던 것, 팀이 안 켜졌던 것 같은 것도 좋습니다."
- 이 답이 발표에서 가장 많이 나오는 질문의 답이 된다. 대충 넘기지 않는다.

✅ 체크포인트: "세 가지 답이 다 나왔나요? 특히 혼자 하면 몇 시간인지가 숫자로 나왔나요?"

# STEP 2. HTML 한 장 만들기 (~8분)

**뼈대를 복사해 값만 채운다.** 백지에서 만들지 않는다.

안내 멘트:
```
이제 한 장으로 뽑겠습니다. 6회차 발표에서 가장 먼저 여실 파일입니다.

  이것으로 2분을 말씀하시고, 그다음 실제로 돌리고, 결과물과 검토 결과를 엽니다.
  발표 자료를 따로 만드실 것 없습니다.
```

Claude 실행 규칙:
- **이 스킬 폴더의 `_리포트_뼈대.html` 을 수강생 폴더에 `에이전트_소개.html` 로 복사한다.**
  `[[ ]]` 로 감싼 자리에 값만 채워 넣는다. 구조와 스타일은 건드리지 않는다.
- **복사한 뒤 맨 위의 안내 주석 덩어리를 지운다.** 수강생이 볼 파일이다.
- `[[ ]]` 가 하나라도 남아 있으면 안 된다. 다 채웠는지 마지막에 훑는다.
- 일곱 절 구성이다. 순서를 바꾸지 않는다.

| 절 | 내용 | 어디서 |
|---|---|---|
| 1 | 무엇을 되게 했나 + 혼자 하면 몇 시간 | 기획안 ① + STEP 1 질문 1 |
| 2 | **구조도** (입력 → 담당자 → 출력) · 누가 무엇을 맡나 | `.claude/agents/` + 운영 스킬 `순서` 칸 |
| 3 | **무엇을 할 수 있나** · 할 수 있는 일 / 하지 않는 일 / 부르는 법 | `CLAUDE.md` ① ④ + 운영 스킬 `언제` 칸과 트리거 |
| 4 | 판단 기준 세 줄 | `CLAUDE.md` ⑥ |
| 5 | 돌린 결과 (실제 칸과 건수 · 실제 행 3건) | 결과 파일 |
| 6 | **검토 요약 두 줄** (3축 숫자 + 한 줄 요약) | `검토결과.md` |
| 7 | 안 된 것과 다음에 할 것 | STEP 1 질문 3 |

**두 HTML의 역할을 가른다.** 발표에서 둘 다 열기 때문에 같은 것을 두 번 보여줄 이유가 없다.

| 문서 | 맡는 것 |
|---|---|
| `에이전트_소개.html` | 무엇을 왜 어떻게. 구조도 · 판단 기준 · 시간 대비 |
| `검토결과.html` | 제대로 도는가. 항목 11개 · 두 번 비교 · 손의 크기 상세 |

그래서 2절에 담당자 표를 다시 넣지 않는다. 구조도로 충분하다.
5절도 3축 숫자와 한 줄 요약까지만 쓰고, 자세한 것은 `검토결과.html` 로 넘긴다.

- **2절의 구조도가 이 문서의 핵심 그림이다.** 입력에서 담당자를 거쳐 출력까지 한 줄로 흐른다.
  - 담당자 칸은 `.claude/agents/` 개수만큼 넣는다. **둘이면 가운데 한 칸과 화살표 하나를 지운다.**
  - 순서는 운영 스킬의 `순서` 칸을 따른다. 담당자 파일 순서가 아니다.
  - `읽기만` 과 `쓰기` 꼬리표는 `tools` 줄을 보고 붙인다. **쓰기는 한 칸에만 붙는다.**
  - 그 아래 `멈추는 자리` 줄에 `CLAUDE.md` ⑤의 내용을 한 줄로 적는다.
    멈출 일이 없는 프로젝트면 `읽기와 새 파일 쓰기만 합니다` 로 적는다.
- **3절은 남이 이 에이전트를 처음 볼 때 가장 먼저 읽는 자리다.**
  - 할 수 있는 일 · `CLAUDE.md` ①번 칸과 운영 스킬의 `언제` 칸에서 서넛을 뽑는다
  - 하지 않는 일 · `CLAUDE.md` ④번 절대 하지 말 것에서 뽑는다. 없으면 판단 기준의 "빼둔다" 줄을 쓴다
  - 부르는 법 · 운영 스킬의 트리거 문장을 그대로. 운영 스킬이 없으면 어떻게 돌리는지 한 줄
  - **없는 것을 지어내지 않는다.** 파일에 없으면 그 줄을 비운다
- **5절에는 실제 결과 세 줄을 넣는다.** 표 이미지가 아니라 진짜 값이다.
  판단 기준에 걸려서 다르게 처리된 건이 있으면 그것을 고른다. 발표에서 짚을 자리다.
- `검토결과.md` 가 없으면 6절을 통째로 뺀다. 빈 절을 남기지 않는다.
- 숫자를 지어내지 않는다. 파일에 있는 것만 쓴다.

**HTML이 지킬 세 조건** (어길 수 없다)

```
① 500KB 미만
② 폭을 좁혀도 가로 스크롤이 없다
③ 바깥에서 아무것도 불러오지 않는다
   글꼴은 컴퓨터에 있는 것으로 쓴다. 웹폰트 선언을 넣지 않는다
   그림이나 차트를 넣을 일이 있으면 파일 안에 담는다
```

만든 뒤 확인한다:
```
에이전트_소개.html 안에 [[ 가 남아 있는지, 그리고 http 로 시작하는 주소나
@font-face 가 있는지 확인해줘. 있으면 어디에 있는지 알려줘.
```

✅ 체크포인트: "`에이전트_소개.html` 이 생겼고, 브라우저로 열어서 일곱 절이 다 보이나요?"

# STEP 3. 실명 점검 (~4분) · 통과 필수

```
이 폴더 안의 파일들을 훑어서, 사람 이름 · 전화번호 · 이메일 · 사내 문서로 보이는 것이
```

그리고 화면 쪽을 확인시킨다:

```
  □ 폴더 이름과 파일 이름에 실명이나 회사명이 없다
  □ HTML 안에 실명이 없다
  □ 바탕화면에 개인 파일이 널려 있지 않다
```

Claude 실행 규칙:

- "회사 자료라 못 보여준다"는 경우: 이름을 지운 사본으로 발표하면 된다고 안내한다. 감점 없다.
- 폴더 이름에 회사명이 있으면 폴더 이름을 바꾸게 한다. **발표 화면에 폴더 이름이 뜬다.**

✅ 체크포인트: "네 칸을 다 확인하셨나요? 실명이 뜨는 자리가 없나요?"

# STEP 4. 발표 준비 안내 (~4분)

## 4-1. 7분에 셋을 보여줍니다

```
발표에서 여실 것은 셋입니다. 미리 탭 세 개를 열어 두세요.

  ① 에이전트_소개.html    무엇을 어떻게 만들었나
  ② 실제 결과물 파일       진짜로 나온 파일
  ③ 검토결과.html         제대로 도는가

순서는 이렇습니다.

  1 · 2분      ① 을 열고 위에서 아래로
                 "이 일을 손으로 여섯 시간 했습니다"
                 구조도를 짚으며 "셋으로 나눴고 쓰는 사람은 한 명입니다"
                 "판단 기준 세 줄입니다. 여기 숫자가 들어가 있습니다"

  2 · 2분 30초  실제로 한 번 돌립니다
                 도는 동안 말합니다. "지금 조사 담당이 읽고 있습니다"

  3 · 1분       ② 방금 나온 결과 파일을 엽니다
                 ★ 판단 기준이 걸린 줄을 짚습니다
                   "이 건은 300자가 안 돼서 요약 안 하고 원문이 들어갔습니다"

  4 · 1분       ③ 을 엽니다
                 "세 축으로 봤습니다. 여기가 미통과였고 이렇게 고쳤습니다"

  5 · 30초      아직 안 되는 것과 다음에 할 것
```

**3번이 발표의 중심이다.** 만든 화면과 실제 실행을 보여준 뒤 **진짜 나온 파일**을 여는 자리다.
판단 기준이 걸린 줄을 짚는 그 한 문장이, 도구를 쓴 사람과 만든 사람을 가른다.

Claude 실행 규칙:
- 세 파일의 **실제 경로**를 `기획안.md` 맨 위에 적어 둔다. 발표 중에 찾지 않게 한다.
- 결과 파일에 판단 기준이 걸린 줄이 없으면, 걸리는 자료 한 건을 그 자리에서 만들어 다시 돌린다.
  짚을 줄이 없으면 3번이 밋밋해진다.

## 4-2. 보험 녹화

```
잘 돌아가는 지금 한 번 찍어 두세요. 이게 보험입니다.

  찍을 구간   돌리기 시작해서 결과 파일이 열릴 때까지
  길이        2~3분이면 충분합니다
  방법        맥은 Shift + Command + 5, 윈도우는 Windows + G

  ★ 발표 중에 안 돌아가면 이걸 틀고 그대로 진행하시면 됩니다. 감점 없습니다.
  ★ "잘 돌아가니까 필요 없다"는 답에는 이렇게 말씀드립니다.
    잘 돌아가는 지금 찍는 것입니다. 안 돌아갈 때는 못 찍습니다.
```

Claude 실행 규칙:
- 녹화 파일 경로를 `기획안.md` 맨 위에 적어 둔다. 급할 때 찾아야 한다.
- 시간이 없으면 녹화만이라도 찍게 한다. 다른 것은 다 미뤄도 된다.

## 4-3. 사고가 나면

`기획안.md` 맨 아래에 붙여 둔다.
