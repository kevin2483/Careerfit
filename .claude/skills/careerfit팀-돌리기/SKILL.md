# CareerFit 팀 돌리기

## 언제
"[직무] 갭 진단해줘" / "[직무]에서 내가 부족한 역량이 뭐야" 한 문장을 받았을 때.
직무는 ds(데이터 사이언티스트) / de(데이터 엔지니어) / mle(ML 엔지니어) / da(데이터 분석가) 중 하나.

## 팀 구성
- 세 에이전트 모두 tools: Read, Bash (Write/Edit 없음)
- 단, Bash가 있으므로 권한만으로 쓰기가 막히는 것은 아니다.
  실제 보장은 각 에이전트가 정해진 스크립트만 호출하고,
  그 스크립트가 자기 out_dir에만 기록한다는 설계 규약이다.
  - extractor → job_skill_extract_report.py → data/processed/job_skill_extract_report/
  - analyst   → market_stats.py            → data/processed/market_stats/
  - diagnoser → gap_diagnosis.py           → 파일 미기록, 표준출력만
- 리더(메인 세션) — 노션 쓰기. 서브에이전트는 노션 MCP 접근 불가.

## 순서 (반드시 직렬 — 팀으로 부르되 동시 실행 금지)
1. **extractor** 실행 (`date`는 최신 공고 수집일로. 하드코딩 금지)
2. **analyst** 실행 (같은 `date`) — extractor 산출물이 없거나 오래되면
   `market_stats.py`의 `check_inputs_fresh()`가 자동으로 멈춘다
3. 리더가 **이력서 텍스트**를 확보한다 (구글 드라이브 MCP를 diagnoser가 직접 못 쓰므로,
   리더가 드라이브에서 읽어 텍스트로 diagnoser에게 넘긴다)
4. **diagnoser** 실행 (`target_job`, 리더가 넘긴 이력서 텍스트) — analyst 산출물이 없거나
   오래되면 `gap_diagnosis.py`의 `check_inputs_fresh()`가 자동으로 멈춘다
5. 리더가 diagnoser의 응답을 노션 'BDAI 실습' 페이지의 "직무 갭진단 실행 기록" 표에 한 줄 추가

## 판단 기준 (스크립트에 코드로 고정돼 있어 매번 같게 나옴)
- (canonical, 직무) 출현 3건 미만 → 순위·비교·동시출현·신입경력 통계에서 제외 (`excluded_lowfreq.csv`)
- 직무 비교는 절대건수 아니고 출현율(%)만. da는 모집단 63(원티드 직군 오염, 121 아님)
- 갭 우선순위 = 출현율(%) × 미보유가중치(현재 이진: 미보유1/보유0) × 신입접근성(0~1). 상위 5=이번 분기
- **field 3(암묵조건) 태그는 학습 로드맵에서 제외** (예: 협업커뮤니케이션 — 거의 모든 공고에 등장해
  변별력 없고, 애초에 "배울 수 있는 항목"이 아님. 2026-08-12 재현성 점검에서 발견해 추가한 기준)

## 멈출 곳 (사람 확인 필요 — 직접 검토해서 고쳐 주세요)
- [ ] diagnoser·analyst가 `SystemExit`으로 멈추면(산출물 없음/오래됨) → 재실행 여부를 사람에게 묻는다
- [ ] 이력서 텍스트를 리더가 못 구했을 때(드라이브 접근 실패 등) → 진단을 진행하지 않고 사람에게 묻는다
- [ ] 사전(skill_tags) 개정 시 → 진단 진행 전 확인
      (v0→v1 개정 때 정답셋 태그명을 함께 갱신하지 않아 개선이 성능하락으로
       보였던 사고 있었음. 2026-08-13 재측정 결과 v0 F1 0.888 → v1 0.915)
- [ ] **학습 로드맵 top5에 "배울 수 없는 항목"이 올라오면 → 진단 결과를 노션에 기록하기 전에
      사람에게 확인받는다.** field 3(암묵조건) 외에도 태그로는 잡히지만 학습 대상이 아닌 것
      (도메인 지식, 자격증, 근무조건 등)이 상위에 뜰 수 있다. 실행 가능한 항목인지 사람이 판단한다.
      (실제 사고: 협업커뮤니케이션이 로드맵 2위로 올라왔음)

## 출력
- 로컬: `data/processed/job_skill_extract_report/`(4종), `data/processed/market_stats/`(4종)
- 노션: 'BDAI 실습' 페이지 → "직무 갭진단 실행 기록" 표(직무·실행일·top5·비고 한 줄 누적)
  + 상세 페이지(top5 전문·후순위·보유역량·field3 제외·재현성 대조·이력서 최신성 한계)
- 모든 표는 항목·값·근거 세 칸 (CLAUDE.md ③)
