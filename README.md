# CareerFit — 채용시장 역량 분석 및 개인 갭 진단 에이전트

채용공고를 수집·분석해 직무별 요구 역량을 구조화하고, 개인 이력과 대조해
역량 갭과 학습 우선순위를 진단하는 프로젝트.

**핵심 차별점:** LLM 추출 결과를 정성적으로 믿지 않고, 자체 정답셋으로
정량 평가한 위에서 비용·정확도를 최적화한다.

## 현재 진행 (1주차)
- **수집**: 원티드 API 리버싱으로 직무별 공고 수집 (`src/crawl/wanted.py`)
- **역량 태그 사전 v0**: 실제 공고 기반 온톨로지, 73개 태그 (`data/raw/dict/skill_tags_v0.yaml`)
- **regex 추출 스킬**: 공고 → 표준 역량 태그 → 직무별 빈도표.
  결정적(같은 입력=같은 출력), 재현 검증 통과 (`src/extract/job_skill_extract_report.py`)

## 데이터 안내
공고 원문(`data/raw/*/*.jsonl`)은 저작권상 저장소에 포함하지 않는다.

## 로드맵
3 역량 추출(regex 완료 / LLM 예정) → 4 추출 성능 평가(정답셋·F1) →
5 모델 캐스케이드(비용·정확도 최적화) → 6 시장 분석 → 7 개인 갭 진단 → 8 에이전트화
